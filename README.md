# AirBorne

AirBorne is a Unity-based third-person controller focused on airborne movement and physics-driven character control.

---

## Features

- Rigidbody-based movement  
- Air control with velocity interpolation  
- Custom gravity for better game feel  
- Ground detection using raycasts  
- Smooth camera-relative movement  
- Animator integration  

---

## Controls

- **W / A / S / D** → Move  
- **Space** → Jump  
- **Mouse** → Camera  

---

## Tech Stack

- Unity  
- C#  
- Rigidbody Physics  
- Animator
